# faculty-time-table-management-system
A Faculty Time Table Management System is basically a web based project that helps colleges/schools create, manage, and view faculty timetables in an easy and automated way.

1. Problem Statement

In many colleges, timetables are still prepared manually using Excel or paper.
This causes:

Clashes in faculty schedules (same teacher at two places at same time)

Wrong room allocation

Difficulty when any change is required (substitution, leave, extra class)

Time-consuming process for admin/HOD

So we propose a Faculty Time Table Management System to solve these issues.

2. Project Description (High-level)

“It is a web-based / desktop-based application designed to automate the process of creating and managing faculty timetables. The system maintains details of courses, subjects, classrooms, and faculty and then generates conflict-free timetables. It also allows admin and faculty to view, update, and manage schedules efficiently.”

3. Main Objectives

To automate timetable generation and reduce manual work

To avoid clashes:

Faculty clash (same faculty in two classes at same time)

Room clash (two classes in same room at same time)

To make it easy to:

Assign subjects to faculty

View individual faculty timetable

Update timetables when there is a change (leave, extra class etc.)

To provide a centralized system for admin, faculty, and optionally students

4. Users of the System

Admin / HOD

Add/edit departments, courses, semesters

Add faculty details and their availability

Add subjects and map them to faculty

Generate and update timetable

Faculty

View their timetable (day-wise, week-wise)

See free hours and allocated hours

View class-wise timetable
